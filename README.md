# Testable Profile Card

This project is a **responsive, accessible Profile Card** built using **semantic HTML**, **modern CSS**, and **vanilla JavaScript**.  
It was created as part of a front-end development task to demonstrate clean code structure, responsiveness, accessibility, and testing readiness using `data-testid` attributes.

---

## Features

- ✅ Semantic HTML structure (`<article>`, `<header>`, `<section>`, `<nav>`, etc.)
- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ Accessible keyboard focus and ARIA labels
- ✅ Dynamic current time using JavaScript (`Date.now()`)
- ✅ Data attributes (`data-testid`) for automated testing
- ✅ Styled using pure CSS (no frameworks)
- ✅ Button-like styling for section headers (Hobbies & Dislikes)

---

##  Technologies Used

- **HTML5**
- **CSS3 (Flexbox, Responsive Design)**
- **Vanilla JavaScript (no frameworks)**

---

##  Structure Overview

| Section | Description |
|----------|--------------|
| `test-profile-card` | Root container for the profile card |
| `test-user-avatar` | User’s profile picture |
| `test-user-name` | Display name |
| `test-user-bio` | Short biography text |
| `test-user-time` | Current time displayed dynamically |
| `test-user-social-links` | List of social media links |
| `test-user-hobbies` | List of hobbies |
| `test-user-dislikes` | List of dislikes |

---

##  Preview

The profile card displays the user's avatar, bio, and social links.  
On larger screens, the layout adapts to position the avatar and content side by side.
